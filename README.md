# Tota Group — TotaVivo Life Companion Build 8.3

Open `index.html` to enter the Tota Group launcher, or open `apps/totavivo/life-companion.html` directly.

This package is a safe consolidation build: it preserves the complete working V7 feature set, upgrades the product naming and group architecture, incorporates all uploaded public/legal/pilot collateral, and creates the correct module boundary for TotaSignal and future Tota services.

For deployment, publish the entire folder as the site root. The TotaVivo PWA files remain together inside `apps/totavivo` so relative assets and offline behavior continue to work.
